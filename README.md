# Проект 5. Learn management system, «система управления обучением», программное обеспечение, предназначенное для управления образовательными процессами

## Техническое задание на разработку веб-приложения с рассылкой сообщений

Создать веб-приложение на Django REST Framework, реализующее следующий функционал:

- Создание и управление курсами. Возможность добавлять модули и уроки, загружать видео, документы, презентации.
- Управление пользователями. Администратор может добавлять новых участников, настраивать доступ к контенту и
  распределять роли (преподаватель, студент, куратор и др.). 
- Система тестирования. Встроенные инструменты для создания опросов, экзаменов и автоматической проверки ответов.
  Отслеживание прогресса. Система собирает статистику по студентам, результатам тестов, успеваемости, востребованности
  курсов. 
- Уведомления и напоминания. Информирование пользователей о новых курсах, дедлайнах и изменениях в расписании. 
- Сертификация. Возможность автоматически выдавать сертификаты по окончании курса и после успешной сдачи экзаменов.
  Интеграции.
- Поддержка соединения с другими сервисами — CRM, мессенджеры, платёжные системы и др..
